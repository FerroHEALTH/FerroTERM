- A SNOMED CT display follows the dialect it is asked for. `displayLanguage=en-US` (or `Accept-Language`) selects the US English preferred term and `en-GB` the GB English one, by the language reference set that ECL Appendix C names for each dialect alias. `terminology.default_language` may name a dialect too, such as `en-US`. A bare `en` takes the edition's English reference sets in ascending SCTID order.
