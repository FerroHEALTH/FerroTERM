- The server, the sync service, the console and the add-ons move to `ferrohealth-smart` 0.10.1, `ferrohealth-session` 0.4.0 and `ferrohealth-config` 0.2.10. An array of tables in the configuration, such as `[[auth.issuer]]`, can now be set from the environment by element index (`FERROTERM__AUTH__ISSUER__0__URL`) or with `--set auth.issuer.0.url=…`, so a deployment configured only through the environment can declare its issuers; an index with a leading zero or one that skips an element is refused at load.
