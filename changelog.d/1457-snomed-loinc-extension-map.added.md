- `$translate` answers the LOINC Extension map `[edition]/version/[date]?fhir_cm=11010000107` both ways, between a SNOMED CT concept and the LOINC code the RF2 identifier file gives it. The map is provisional: the tx-ecosystem IG's test edition notes are its only source. A `$translate` that names no map now finds the implicit maps of the loaded code systems between the source and the target system, a `targetSystem` may carry `|version`, and implicit URIs work on an unpublished edition's `http://snomed.info/xsct/` URIs.
