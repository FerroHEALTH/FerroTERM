- `$translate` converts an extension's SNOMED CT concepts into an edition it depends on through `[edition]/version/[date]?fhir_cm=edition/[module]`, found by `targetSystem=http://snomed.info/sct|http://snomed.info/sct/[module]`: a target concept to itself, an inactive one through SAME AS or REPLACED BY, a defined one to the target concept with the same definition or else to an expression over the target's concepts, and a primitive one to its nearest target supertypes as wider. The build keeps the Module Dependency rows, which give the target version, so an index must be rebuilt for the map to answer.
