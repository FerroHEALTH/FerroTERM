- `ConceptMap/$translate` on `/r4` and `/r4b` accepts the `targetcode` form of a reverse translation beside `reverse`, as the HL7 terminology ecosystem IG requires of an R4 server: `targetcode` is the code to translate back, `targetsystem` its code system and `system` the one to translate into. A match whose target is not in its code system's normal form, such as a code of a case-insensitive code system written in another case, keeps `concept` as the map states it and adds the ecosystem's `normalized-concept` part with the code as the code system defines it. The tx-ecosystem suite passes one more `general` case on `/r4`: 745 of 805.
