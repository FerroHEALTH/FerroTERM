- The NTS add-on no longer logs in with the resource owner password grant or a refresh token, and the sync service's `[nts]` section no longer takes `username`, `password` or `password_file`; each is refused at load. RFC 9700 §2.4 says the password grant MUST NOT be used, and the NTS realm publishes the client credentials grant. Set `nts.client_id` and `nts.client_secret` (or `nts.client_secret_file`) to a confidential client Nictiz issues.
