- `$validate-code` on a SNOMED CT expression answers `code` as you sent it, in `ValueSet/$validate-code` too. The normal form is written with no whitespace and no `===` (`39607008:272741003=24028007`), and so is an expression's display, with the terms written in. A code that differs from the normal form only by whitespace, terms or a leading `===` is in normal form. Any other spelling gets the normal form as `normalized-code` with a `CODE_NOT_IN_NORMAL_FORM` information issue, which replaces the "alternate form" note on every code system. The display keeps each term you wrote that is an active description of its concept.
