- `$subsumes` over BCP 13 media types reads the parameter defaults the defining RFCs give into the bare type, as the HL7 terminology ecosystem IG requires: `text/plain` is `charset=us-ascii` (RFC 6657 §4) and `format=fixed` (RFC 3676 §4). So `text/plain` and `text/plain; charset=us-ascii` are `equivalent`, and `text/plain; charset=utf-8` is `not-subsumed` where it used to be subsumed. A `text/*` type whose default charset is not stated, such as `text/csv`, is refused when a charset is compared with its absence.
