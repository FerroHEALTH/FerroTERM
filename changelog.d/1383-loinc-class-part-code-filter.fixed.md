- A LOINC `CLASS` filter takes the Part code of a class as well as the class name, and an axis filter that names a Part by its name matches the Part's `PartName` alone, never another Part's `PartDisplayName`, as the HL7 terminology ecosystem IG's LOINC section requires. A LOINC index built before this release has no Part types, so rebuild it with `ferroterm-build --loinc` to filter `CLASS` by a Part code.
