- Breaking: the console is rewritten on FerroUI 0.3.2 (`ferrohealth-ui` =0.3.2) in Leptos islands mode. Every page is drawn whole on the console's server and works with scripting off; every change is a plain form post to the page's own address, answered by a redirect, and the WebAssembly carries only FerroUI's islands (the theme menu, the copy buttons, the concept tree, the toasts, the repeat rows) and the keyboard shortcuts. The server functions under `/api/` are gone. The sign-in routes move: `/login` is `/auth/login`, `/logout` is `/auth/sign-out`, and `/auth/sign-in` is a page of its own that says why a reader is there (signed out, expired, refused). The screens follow the FerroUI design: binder tabs on each resource (Overview, Versions, History and JSON for a code system; Definition, Expansion and JSON for a value set; Mappings, Overview and JSON for a concept map), the four runners under one Operations screen, About split into Server (the roots, their operations and the build's evidence), Configuration and About, and Your preferences opened from the menu under your name in three tabs. The navigation entries are plain paths, and the version menu keeps the FHIR version for the session. The editors draw their Save in a docked bar (`Ctrl S`) and keep a refused draft in the form; a restore on the revisions screen asks first in a dialog and the page says which revision it wrote. The preferences are one cookie each, named `ferroterm_console_<key>`: the display language moves from `ferroterm_console_language` to `ferroterm_console_display-language` (`ferroterm_console_language` is now the console's own language), the page size from `ferroterm_console_page_size` to `ferroterm_console_page-size`, and the default page size is 25 rows, where it was 50. The composer takes a clause's codes typed one per row, and the list of recent runs on the operation screens is dropped. Upgrade: point bookmarks and the identity provider's links at `/auth/login` and `/auth/sign-out` (the registered redirect address `/auth/callback` is unchanged); readers choose their display language and page size again once, in Your preferences.
