- `ferroterm-build --fhir-package <TGZ>` imports an operator-supplied FHIR NPM package, such as the MyHealth@EU Master Value Sets Catalogue, into `<out>/<name>-<version>/` for `terminology.code_systems`, keeping each `CodeSystem`, `ValueSet` and `ConceptMap` with its canonical and version. `--fhir-package-sha256` refuses a file whose digest differs from the pin, and two releases load side by side and answer by `valueSetVersion`. FerroTERM ships no MVC content: the operator holds the licences and supplies the package.
