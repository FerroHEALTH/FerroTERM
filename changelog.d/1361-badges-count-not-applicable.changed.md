- The tx-ecosystem badges show how many of the 805 `general` cases do not apply on each surface, for example `742 / 805 (5 n/a)` on R4. The count comes from `conformance/tx-ecosystem/not-applicable.tsv`, which lists each case and its reason: the case's own mode or version gate skips it, or it fails on `/r4b` only because the suite targets R4 and R5. Every `general` run holds that file to the runner's skips.
