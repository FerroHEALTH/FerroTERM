- The NTS add-on obtains its token through `ferrohealth-smart`'s client credentials `TokenSource`, which reads the token endpoint from the realm's OpenID Connect Discovery metadata, caches the token and renews it a minute before it expires. A `[[source]]` block of the add-on takes `issuer`, which defaults to `https://terminologieserver.nl/authorisation/auth/realms/nictiz`, in place of reading `<base>/fhir/.well-known/smart-configuration`. `nts.client_id` has no default any more.
