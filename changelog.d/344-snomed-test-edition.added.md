- `ferroterm-build` loads the HL7 terminology ecosystem's own SNOMED CT test edition, which the IG repository ships under `tx-source/snomed`. `--rf2-unpublished` names an edition under `http://snomed.info/xsct/`, as the SNOMED CT URI Standard names an unpublished release. The build now reads every concept file and every module dependency file of a release, one per namespace, where it used to read only the first. A module dependency member that names its own module no longer hides the edition module. A concrete value of `true` or `false` loads as a boolean, which ECL's boolean comparison reads. Over that edition, the tx-ecosystem `snomed` mode passes 189 of 378 cases, where it passed 2.
