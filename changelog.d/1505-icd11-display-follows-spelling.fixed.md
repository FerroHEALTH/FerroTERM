- An ICD-11 postcoordination expression's display follows the spelling the request sent, in `$validate-code`, `$lookup`, value set validation and expansion. Before, two spellings of one expression shared one stored display, so a concurrent request, or a value set that enumerates the expression in another spelling, could answer with the other spelling's display. With no spelling to follow, the display renders the normal form. Code system providers gain `CodeSystemProvider::spelled_display`, which answers as `display` unless the system's display follows the spelling, and `MapSelection` and `Successor` move to `provider::concept_map`.
