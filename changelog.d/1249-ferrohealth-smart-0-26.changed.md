- FerroTERM moves to `ferrohealth-smart` 0.26, with `ferrohealth-session` 0.21, `ferrohealth-server` 0.10 and `ferrobridge-term` 0.11, the releases on the same line. A Basic user's scopes and roles move from `[[auth.basic.users]]` to the new top-level `[basic_grants]` table of the server and the sync service, one `[basic_grants.<user>]` table per user-id. A `scopes` or `roles` key under `[[auth.basic.users]]` is now refused as an unknown key. A grant naming a user `[[auth.basic.users]]` does not list refuses the start, and so does a grant of a `system/` scope. `[server] max_concurrent_requests` is always on, 256 by default, where it was unbounded when unset (#1249).
