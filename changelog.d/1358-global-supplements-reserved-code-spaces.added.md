- Global supplements and reserved code spaces, as the HL7 terminology ecosystem IG requires them. A global language pack or `extension-codes` supplement (`codesystem-supplement-global`) applies to the code system it supplements without being named, and `$expand` reports it as `used-supplement`. Any other supplement applies only when `useSupplement` or the value set names it. A code in a reserved code space (`codesystem-reservedCodeSpace`) is a valid code, with its `default-display` or `User-assigned`, which is a placeholder any display may replace. An `extension-codes` supplement gives such a code its display: a global one's is binding, and another one's is a suggestion, so a different display is only a warning. An expansion lists a reserved code only where the value set lists it, never through a filter, and an expansion of all of such a code system is marked unclosed. The tx-ecosystem suite passes 26 more `general` cases on each surface: 742 of 805 on `/r4` and `/r5`, and 728 on `/r4b`.
