- `$validate-code` checks a post-coordinated SNOMED CT expression against the concept model the edition carries in its MRCM reference sets: each attribute's domain, grouping, cardinality and range, concrete values against their `int()`, `dec()`, `str()` and `bool()` ranges, and that every attribute is a concept model attribute. Only the rules for postcoordinated content apply; a mandatory rule broken refuses the expression and an optional one is a warning beside a `true` result. A refused expression answers the `invalid-code` error and an `information` issue naming every rule it breaks. The snomed mode passes 294 of 378 on `/r4b`.
