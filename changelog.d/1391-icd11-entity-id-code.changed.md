- ICD-11 MMS and ICF codes are entity ids, as the HL7 terminology ecosystem IG's ICD-11 page defines them. The entity id (`257068234`, `1363559646/other`) is the code and the normal form. The short classification code (`1A00`) is still accepted as an alternative spelling: `$validate-code` reports it valid but not in normal form, with the id as `normalized-code`. A postcoordination expression's code is its entity-id form, so an expression written in classification codes is answered in id form. `$lookup` and expansions answer the `code` property as the id, the short code as the new `classificationCode` property, and `parent` and `child` as ids. The implicit scale value sets include their values by id. A text filter also matches the start of a classification code (`XN8` finds `XN8P1`). A code outside the value set is named as given in the `not-in-vs` message and gets no `normalized-code`. The tx-ecosystem `icd-11` mode passes 25 of 145, up from 10. The crate line moves to 0.16.0.
